## 一、实验室物理基础设施与测速探针拓扑 (E-E-A-T 实体档案)

为了确保 42 家机场评测数据的科学性与可复现性，本平台不依赖虚假的第三方转发数据，而是自建并维护标准化的网络可观测探针矩阵：

### 1.1 国内探测锚点机房分布
- **华南锚点（电信 / 联通骨干）**：位于广东广州 BGP 核心机房，直连中国电信 ChinaNet 出口与中国联通 169 骨干网，测试带宽为物理独享 1,000Mbps 对称宽带，用于捕获华南用户直连深圳、广州各 IEPL / IPLC 专线入口端内网抖动与丢包率。
- **华东锚点（多线 BGP）**：位于上海张江高科技园区机房，覆盖移动、电信、联通与教育网四大物理出口，专用于检测长三角地区过境出口与亚太各直连/专线中继链路的晚高峰（20:00 - 23:30）拥塞排队延迟。
- **华北锚点（联通 / 移动）**：位于北京海淀区，重点监测京津冀及华北区域至日本东京（NRT）、韩国首尔（ICN）及欧洲法兰克福（FRA）的经纬度路由回包。

### 1.2 自动化测试工具链与指标定义
所有网络测试均通过自动化脚本周期性触发，严禁使用浏览器 Speedtest 网页端前端缓存数据：
1. **真实物理带宽吞吐 (Throughput)**：使用原生 Python / Go 编译的 `speedtest-cli` 及 `iperf3` 客户端，多线程并发（8-16 线程）测定单节点极限拉流峰值与稳定中位数。
2. **路由追踪与丢包率 (MTR / Traceroute)**：采用 `mtr --report --report-cycles 100` 对节点落地 IP 进行连续 100 次 ICMP/UDP 探针扫描，精确定位故障跳数是发生在国内骨干网、专线入口内网，抑或海外落地机房 ISP。
3. **流媒体与 AI 全区解锁校验 (Unblock Verification)**：通过专用 Docker 容器沙箱，自动化模拟原生住宅 ISP 发起握手请求，核验是否支持 Netflix 非自制剧（Non-Originals）、Disney+ 4K HDR、YouTube Premium 与 OpenAI ChatGPT / Anthropic Claude 原生落地解析。
