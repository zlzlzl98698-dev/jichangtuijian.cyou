## 一、Android 操作系统平台代理机制深度解析

在 Android 体系中，代理工具的底层运行逻辑高度依赖于官方框架：

```mermaid
flowchart TD
    AppLayer[Android 应用程序 App] --> NetFilter{分应用代理过滤器 (Split Tunneling)}
    
    NetFilter -->|排除名单: 微信 / 支付宝 / 手机银行| SysDirect[物理网络直出 / 绕过代理]
    NetFilter -->|选定名单: Chrome / Telegram / YouTube| VpnPipe[Android VpnService 虚拟隧道]
    
    VpnPipe --> ClientCore[客户端代理核心 Xray / Mihomo / sing-box]
    ClientCore --> ProtectCall[系统底层 protect() 接口防止回环]
    
    ClientCore --> RoutingEngine{DNS 解析与 GeoIP 规则}
    RoutingEngine -->|国内直连 IP| PhyNic[蜂窝基带 / Wi-Fi 直连]
    RoutingEngine -->|海外受阻域名 / AI| NodeTunnel[机场高带宽加密隧道]
    
    subgraph OEMKiller[厂商激进省电与后台冻结]
        Doze[Doze 深度睡眠]
        AppKiller[OOM 内存强杀]
        Freezer[CPU 挂起墓碑]
    end
    OEMKiller -.->|威胁进程生命周期| ClientCore
```

### 1. VpnService 与 `protect()` 保护机制
- **无需 Root 即可全局接管**：自 Android 4.0 引入 `android.net.VpnService` 以来，第三方应用即可向系统申请建立本地虚拟网络接口（通常为 `tun0`）。一旦用户在系统弹窗中确认信任该应用，系统三层（IP 层）的全部数据包都会重定向到该虚拟网卡。
- **防止网络死循环的 `protect()` 核心机制**：代理客户端向境外服务器发送加密握手包时，本身也必须通过物理网卡发出网络请求。为防止客户端自己的外出流量又被重新捕获回 `tun0` 导致致命的死循环，Android 底层提供了 `VpnService.protect(int socket)` 方法。该方法通知系统内核：“这个 Socket 发出的数据包直接走底层物理接口，禁止重新路由到 VPN 虚拟网卡”。

### 2. 国内定制 ROM 的后台杀进程机制与应对
原版 Android 在灭屏后有一套标准的 Doze 阶梯式休眠机制。但国内定制系统为了跑分与续航，引入了极其激进的进程管理：
1. **OOM 优先级压制**：只要前台开启大型游戏或相机，系统会迅速调高代理后台进程的 `oom_score`，优先将代理核心杀掉以释放内存；
2. **广播切断与网络断流**：灭屏 10-15 分钟后，系统自动冻结后台网络连接池，导致常驻的 TCP 长连接被无情丢弃；
3. **墓碑挂起机制**：将进程的 CPU 核心唤醒时隙全部剥夺，导致代理内核无法响应任何本地请求。

要彻底解决这一问题，必须在系统设置中为客户端配置 **「无限制电池优化」**、**「自启动白名单」** 并 **「锁定后台多任务卡片」**。

## 四、Android 核心系统级调优：各大定制 ROM 终极防杀保活

若想让客户端在后台 24 小时稳定运行不掉线，必须按各大厂商规范完成以下保活设置：

### 1. 小米 / Redmi（MIUI / 澎湃 HyperOS）
1. **多任务卡片锁定**：呼出多任务管理界面，长按客户端卡片，点击出现的小锁头图标，将其锁定；
2. **电池优化设置**：打开系统「设置」->「应用设置」->「应用管理」-> 找到客户端 ->「省电策略」-> 勾选 **「无限制」**（切勿选择“智能限制”）；
3. **自启动与权限**：在同一页面中，勾选「自启动」与「关联启动」，并将「权限管理」中的后台弹出界面等权限开启。

### 2. OPPO / OnePlus / 魅族（ColorOS / Flyme）
1. 打开系统「设置」->「电池」->「更多电池设置」->「耗电异常优化」-> 找到客户端，设为 **「不优化」**；
2. 进入「应用管理」-> 点击客户端 ->「耗电管理」-> 打开 **「允许完全后台行为」** 与 **「允许自启动」**；
3. 多任务界面下拉客户端卡片完成锁定。

### 3. vivo / iQOO（OriginOS）
1. 打开系统「设置」->「电池」->「后台耗电管理」-> 找到客户端，修改为 **「允许高耗电」**；
2. 进入「权限管理」->「自启动」-> 开启客户端自启动权限；
3. 在系统加速列表中将客户端加入防误杀清理白名单。

### 4. 华为 / 荣耀（HarmonyOS / MagicOS）
1. 打开系统「设置」->「应用和服务」->「应用启动管理」；
2. 找到客户端，关闭自动管理，弹窗中勾选 **「允许自启动」**、**「允许关联启动」**、**「允许后台活动」** 三个全部允许；
3. 进入「设置」->「电池」-> 取消「低电量模式」。

## 五、分应用代理（Split Tunneling）配置与实战

安卓平台最大的优势之一就是可以对每一个 App 实施细粒度的分流控制。很多国内特定软件（如交管 12123、个人所得税、手机银行 App）在检测到系统开启了代理环境后会报错或闪退。

### 在客户端中配置分应用隔离：
1. 打开客户端（以 v2rayNG 为例）设置 ->「分应用代理」；
2. 开启右上角总开关，模式推荐选择 **「绕过所选应用 (Bypass Selected)」**；
3. 在列表中勾选以下软件（它们将完全绕过代理，直接通过纯净物理基带上网）：
   - **手机银行类**：招商银行、中国工商银行、中国建设银行、中国农业银行等；
   - **政务与民生类**：个人所得税、交管 12123、国家反诈中心、微信、支付宝；
   - **国内音乐与视频版权类**：网易云音乐、QQ 音乐（防止海外 IP 导致国内版权歌曲变灰）。
4. 勾选完成后返回即可生效。从此无需频繁开关代理，兼顾日常安全与境外畅联。

## 七、Android 故障排查字典与常见报错解决指南

### 1. 报错：锁屏休眠数分钟后断网，按电源键亮屏后才瞬间恢复连网
- **原因分析**：这是典型的国产系统 Doze 机制将客户端挂起切断了网络监听。
- **排查解决**：严格按照本文第四节操作，将「电池优化」设为无限制，并在多任务栏给客户端“加锁”。同时检查系统是否开启了“锁屏自动清理后台”策略并将其关闭。

### 2. 报错：手机银行 App 启动时弹窗警告“检测到不安全的网络/VPN，强制退出”
- **原因分析**：部分金融安全 SDK 通过读取 Android 底层 `NetworkCapabilities.hasTransport(TRANSPORT_VPN)` 判断当前存在代理通道，认定处于钓鱼或中间人攻击风险中。
- **排查解决**：使用客户端的「分应用代理」功能，将该银行 App 彻底移入排除直连名单，或开启客户端的“隐藏底层 VPN 标记”功能。

### 3. 报错：Google Play 商店下载应用卡在“等待下载”或 0%
- **原因分析**：Google Play 的后台下载服务由系统底层的 `com.android.providers.downloads`（下载管理器）接管，若分应用代理漏选了下载管理器，会导致下载连接直连超时。
- **排查解决**：在分应用代理设置中，点击右上角勾选「显示系统应用」，找到「下载管理器」与「Google Play 商店」，确保它们均允许走代理。

### 4. 报错：开启代理后，手机开热点给笔记本电脑，笔记本无法打开网页
- **原因分析**：Android 系统的热点流量转发在内核 iptables 中走的是 `FORWARD` 链，默认直接在 Wi-Fi 芯片与 4G/5G 基带间硬转发，不流入本机的 `tun0` 接口。
- **排查解决**：在客户端设置中开启「允许来自局域网的连接 (Allow LAN)」，并在笔记本电脑的网络设置中，将 HTTP/Socks5 代理填入手机热点的局域网 IP（通常为 `192.168.43.1`）与客户端端口。

### 5. 报错：节点 Ping 测速全部显示 -1 或连接失败
- **原因分析**：1. 系统时间误差超标，进入安卓「设置」->「系统和更新」->「日期和时间」，打开「自动设置」；2. 订阅节点已被 GFW 阻断，请在客户端更新最新订阅；3. 本地 APN 接入点被运营商分配了纯 IPv6 地址，在 APN 设置中改为 `IPv4/IPv6` 双栈。

## 八、Android 平台 10 大真实痛点 FAQ

### Q1: 安卓手机使用代理客户端，会增加耗电量吗？
**A**: 会有轻微增加，但绝非系统电池统计显示的那么夸张。代理客户端本身仅对数据包做快速解密与转发，纯 CPU 开销通常只占 2%-5%。之所以电池统计里显示“耗电大户”，是因为所有流经该 VPN 的 App 所消耗的网络射频功耗都被系统归纳到代理客户端账上。

### Q2: 为什么有些客户端界面是全英文，有汉化版吗？
**A**: v2rayNG、FlClash 与 CMFA 均内置了完整的简体中文语言支持。进入客户端自身的设置（Settings）界面，找到「Language（语言）」选项，手动选择「简体中文」或「Follow System（跟随系统）」即可。

### Q3: 使用原版 Clash for Android (CFA) 还能用吗？
**A**: 不建议继续使用。原版 CFA 开发者已于 2023 年底归档删库，其内置的 Clash 核心无法支持较新的 VLESS-Reality、Hysteria2 协议。推荐平替迁移至 **FlClash** 或 **Clash Meta for Android (CMFA)**。

### Q4: 手机刷了第三方原生类原生系统（如 LineageOS / PixelExperience），还需要防杀后台吗？
**A**: 不需要。原生 Android 遵循标准 AOSP 规范，只要给予了 VpnService 权限并忽略标准电池优化，系统绝不会像国产定制 ROM 那样恶意强杀有活跃网络连接的前台服务。

### Q5: 为什么连接代理后国内软件（如高德地图、美团）定位跑到香港或美国去了？
**A**: 这是因为路由规则配置错误，导致高德/美团的定位服务器走到了海外节点，服务器通过出站 IP 将你反向定位到了节点所在地。请务必将路由模式改为「绕过大陆和局域网」或「规则分流模式」。

### Q6: 为什么安卓上有些节点的延时只有 10ms，但打开网页依然转圈？
**A**: 请注意测速方式的区别。很多客户端默认测速是“ICMP Ping”，它只测你手机到国内中转入口服务器的物理距离（专线入口就在国内，当然只有十几毫秒）；而只有使用“TCP Ping”或“真实握手延迟（True Delay）”，才能测出整条链路到达境外目标服务器的真实可用性。

### Q7: 开启客户端后微信收到新消息不再弹窗提醒了？
**A**: 微信后台推送在安卓上主要依赖微信自身的后台守护进程或国内统一推送联盟（PUSH）。请进入手机设置，确保微信本身的后台活动权限与通知权限完全开启，并在分应用代理中将微信设为直连。

### Q8: 可以在两台安卓手机之间直接蓝牙或 Wi-Fi 传配置文件吗？
**A**: 可以。v2rayNG 支持直接将任意单节点或整个订阅导出为二维码。在第一台手机上点击节点分享二维码，第二台手机打开 v2rayNG 点击右上角扫描屏幕二维码，即可在 1 秒内无损同步节点配置。

### Q9: 华为鸿蒙系统（HarmonyOS）目前还能安装并正常运行这些客户端吗？
**A**: 在目前的 HarmonyOS 3/4 等基于 AOSP 兼容层的版本中，完全可以直接下载安装 APK 文件并正常使用；若后续升级为纯血鸿蒙（HarmonyOS NEXT），则需要等待各大开源社区针对原生鸿蒙 ArkTS 开发相应的 Native 应用。

### Q10: 订阅链接在安卓端经常更新失败提示“Connect Timeout”？
**A**: 大陆三大运营商的 5G 基站在部分省份会对包含特定关键词的订阅域名发起 DNS 阻断。解决办法：切换到 Wi-Fi 环境重试，或者在客户端设置中将本地 DNS 改为腾讯 `119.29.29.29` 或阿里 `223.5.5.5` 后再执行更新。
