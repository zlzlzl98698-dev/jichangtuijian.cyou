# 2026 全平台机场代理客户端下载与配置大全

机场代理客户端主要分为两大类别：
1. **第三方通用客户端**：如 Clash Verge Rev、v2rayN、Shadowrocket、FlClash、Hiddify，可灵活导入任何兼容的机场订阅链接，支持规则分流与自定义路由。
2. **机场自研专属客户端**：由特定机场服务商提供，免去复杂的订阅配置，下载登录账号即可一键使用。
