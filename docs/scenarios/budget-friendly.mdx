## 七、平价机场故障排查字典与常见报错解决指南

### 7.1 报错：晚高峰 21:00 节点提示“连接超时 (i/o timeout / EOF)”
- **原因拆解**：平价机场在晚高峰瞬时并发人数激增，超售带宽池达到饱和，部分后发起的 TCP 连接在网关排队超时。
- **解决步骤**：
  1. 切换至同机场内负载较低的次选节点（如将“香港 01”换为“新加坡”或“台湾”）。
  2. 若依然超时，直接将策略组无感切换至光速云主力物理专线。

### 7.2 报错：买的 60GB 流量明明没怎么用，几天就显示耗尽
- **原因拆解**：
  1. 误连入了标注为 2x~3x 的高倍率节点。
  2. Windows 后台自动更新或 OneDrive 同步在静默跑流量。
- **解决步骤**：
  1. 检查节点名称后缀，只连标注 `1.0x` 的标准节点。
  2. 在客户端规则中加入对 Windows Update 域名的 `DIRECT` 直连放行。

### 7.3 报错：平价订阅链接在客户端更新失败，报 SSL 证书错误
- **原因拆解**：平价机场的主订阅域名被墙阻断，或者服务端 Let's Encrypt 证书轮换时配置异常。
- **解决步骤**：
  1. 开启手机热点或连入备用节点，勾选客户端的“允许通过当前代理更新订阅”。
  2. 登录机场官网后台，复制最新的备用动态订阅链接。

### Q1：5.6 元的机场和 30 元的机场，到底差在哪里？
