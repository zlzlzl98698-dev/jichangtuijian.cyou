## 六、全平台客户端部署配置与极简上手指引

龙猫云以全方位详尽的图文教程著称，以下为最推荐的部署路径：

### 6.1 Windows 平台（Clash Verge Rev）
1. 登录 <a href="https://guangs.flycataff.com/#/?code=6uq0Xe9y" target="_blank" rel="nofollow sponsored noopener">龙猫云官方控制台</a>，复制「Clash 订阅地址」。
2. 打开 **[Clash Verge Rev](/docs/clients/windows)**，进入「订阅」界面粘贴地址并点击「导入」。
3. 导入后在「设置」中开启「TUN 模式 (虚拟网卡)」，接管系统全局流量。
4. 在「代理」面板选择「规则 (Rule)」模式，将默认策略指定给「香港 IPLC 专线 01」。

### 6.2 软路由配置指引（OpenClash / PassWall）
> **家庭网络全屋透明加速**：龙猫云对 Shadowsocks 的完美支持，使其成为软路由的绝佳搭档。
1. 登录 OpenWrt 软路由后台，进入「服务」->「OpenClash」或「PassWall」。
2. 在订阅管理中添加龙猫云的 Shadowsocks 订阅链接，勾选「自动更新」。
3. 模式选择「Fake-IP (TUN 模式)」或「中国大陆 IP 走直连」，保存并应用。
4. 部署完成后，全家连入 Wi-Fi 的所有设备（包括电视盒子、手机、扫地机器人）均可直接科学上网。

### 6.3 iOS 苹果手机配置（Shadowrocket / 小火箭）
1. 打开 **[Shadowrocket](/docs/clients/ios)**，点击右上角 `+`，类型选择 `Subscribe`。
2. 粘贴龙猫云订阅链接，备注填“龙猫云”，保存并下拉刷新。
3. 全局路由选择「配置 (Config)」，轻触首行开关连接即可。
