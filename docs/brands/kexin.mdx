## 六、全平台客户端部署配置与极简上手指引

可信云完全支持主流开源第三方客户端，提供纯净的订阅链接导入：

### 6.1 Windows / macOS 桌面端（Clash Verge Rev 推荐）
1. 登录可信云官网后台，在用户中心点击「一键导入」或「复制 Clash 订阅链接」；
2. 打开 **[Clash Verge Rev](/docs/clients/windows)**（基于 Mihomo 现代内核）；
3. 进入「订阅 (Profiles)」界面，粘贴订阅链接并点击「导入 (Import)」；
4. 右键该订阅卡片，设置自动更新周期为 **1440 分钟（24小时）**；
5. 进入「设置」开启「TUN 模式」，代理规则选择「规则模式 (Rule)」，并将策略组指向「香港 IEPL 专线 01」。

### 6.2 iOS 苹果端配置（Shadowrocket / 小火箭）
1. 打开海外 Apple ID 登录的 App Store 下载 **[Shadowrocket](/docs/clients/ios)**；
2. 打开小火箭，点击右上角 `+`，类型选择 `Subscribe`；
3. 粘贴可信云的订阅 URL，备注填写“可信云”，点击右上角完成；
4. 全局路由选择「配置 (Config)」以启用智能分流，轻触顶部开关即可连接。

### 6.3 Android 安卓端配置（v2rayNG / FlClash）
- 下载安装 **v2rayNG** 或 **FlClash**，粘贴订阅链接更新节点，开启「分流设置」即可无缝使用。
