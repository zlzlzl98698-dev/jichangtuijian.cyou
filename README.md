## 📖 项目概述 (Overview)

**机场 cyou (`jichangtuijian.cyou`)** 是一个面向现代化跨境网络加速、开发者学术出海、跨境电商合规运营与流媒体极客的高端可观测性平台。

不同于传统个人博客或营销号的碎片化推荐，本项目采用 **软件工程化思维 + 网络可观测性探针遥测**，建立了一套严格量化的评测指标体系，涵盖：
- **物理专线拓扑分析**：IEPL / IPLC 专线入口端内网抖动、丢包率与过境 MTR 路由跳数拆解；
- **真实晚高峰极限压测**：基于广州电信/联通、上海多线 BGP、北京海淀三地物理探测探针，连续 100 次并发吞吐采样；
- **全区解锁自动化校验**：针对 Netflix 非自制剧（Non-Originals）、Disney+ 4K HDR、YouTube Premium、OpenAI ChatGPT 及 Claude 原生落地 IP 定期复测。

## 🚀 快速上手 (Quick Start)

### 1. 环境准备
确保本机已安装 Node.js (推荐 v20.0 或更高版本) 及 git。

```bash
node -v   # >= v20.0.0
npm -v
```

### 2. 克隆项目
```bash
git clone https://github.com/zlzlzl98698-dev/jichangtuijian.cyou.git
cd jichangtuijian.cyou
```

### 3. 安装依赖
```bash
npm install
```

### 4. 启动本地开发服务器
```bash
npm run start
```
访问 `http://localhost:3000` 即可在本地实时预览文档及交互页面。

### 5. 生产环境构建与测试
```bash
# 静态资源预编译
npm run build

# 本地预览生产构建产物
npm run serve
```

本项目完全解耦为无状态纯静态文件，可无缝部署至任意现代 CDN / 边缘托管网络：

### Cloudflare Pages (推荐)
1. 连接 GitHub 仓库至 Cloudflare Dashboard；

3. 构建命令：`npm run build`；
4. 输出目录：`build`；
5. 环境变量：`NODE_VERSION = 20`。

### Vercel / Netlify
- Framework Preset: `Docusaurus`
- Build Command: `npm run build`
- Output Directory: `build`
